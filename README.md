# 煤矿井下设备与工种图文识别图库

# Chinese Coal Mine Underground Equipment & Worker Image Library

一个面向**煤矿井下设备认知与安全培训**的图文图库：收录井下常见设备的结构示意图、中文标注、识别要点，以及煤矿特种作业工种说明。每一张图都配"是什么 / 长什么样 / 装在哪 / 起什么作用 / 检查要点 / 隐患后果"讲解，适合新人学习、现场对照、拍照识别。

> **当前规模**：清单 150 项，**已入库 134 张教学示意图**，另 4 项复用已有图（G/H 类引用 A/B 类），12 项按福庆煤矿实际跳过（无瓦斯矿不涉瓦斯/爆破作业、综采综掘不用炮掘爆破、无立井不涉罐笼箕斗）。图库面向无瓦斯、一采两掘（综采+综掘）的矿井场景整理。

A visual library for **coal mine underground equipment recognition and safety training**. Each image comes with Chinese labels and structured explanations (what it is / appearance / location / function / inspection points / hazard consequences).

> ⚠️ **重要声明**：本图库图片为 **AI 生成的教学示意图**，非真实设备实拍照片，用于学习认知与识别训练。真实设备因厂家型号不同存在差异，现场作业请以本矿规程和实物为准。图片采用 CC BY-NC-SA 4.0 协议，仅限非商业学习使用，转载请署名。

## 目录结构 / Structure

```
images/
├── A-采煤工作面/    # 采煤机、滚筒、截齿、液压支架、刮板机等
├── B-掘进工作面/    # 掘进机、截割头、锚杆钻机、局扇、风筒等
├── C-运输/          # 皮带机、矿车、电机车、无轨胶轮车等
├── D-通风/          # 风门、密闭、风桥、调节风窗等
├── E-排水防治水/    # 排水泵、管路、探放水钻机等
├── F-供电电气/      # 开关、电缆、接线盒、矿灯等
├── G-监测监控/      # CO/温度/风速传感器、分站、人员定位、标校气样（无瓦斯矿不含瓦斯探头）
├── H-顶板支护/      # U型钢棚、工字钢棚、木垛、离层仪、矿压站（支架/单体柱/π型梁见A类）
├── I-防尘隔爆/      # 隔爆水棚、喷雾、消防库、灭火器、岩粉棚等
├── J-提升井筒/      # 提升机、钢丝绳、猴车、井架、天轮（无立井不含罐笼箕斗）
├── K-爆破/          # （空）福庆综采综掘不用炮掘爆破，跳过
├── L-安全救护/      # 自救器、避难硐室、压风/供水施救、安全帽、反光服、防尘口罩
├── M-工具量具/      # 力矩扳手、拉力计、测力计、卷尺
└── N-工种岗位/      # 10个煤矿特种作业（无瓦斯矿保留6个）+ 8个常见岗位
```

## 使用建议 / Usage

1. 想认识某设备 → 按类别目录找图，对照中文标注识别部件。
2. 拍照识别 → 将照片与本图库及识别清单的"识别要点"对照。
3. 培训教学 → 图片+讲解可直接用于新人安全培训材料（非商业）。
